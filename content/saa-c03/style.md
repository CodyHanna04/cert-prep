- **Level:** associate solutions architect. A short business scenario with requirements and one constraint, solved by choosing or combining AWS services in a well-known pattern: Multi-AZ vs read replicas, SQS to decouple tiers, CloudFront in front of S3, a gateway VPC endpoint to avoid NAT costs, pilot light vs warm standby, Savings Plans vs Spot. The guide's verbs are design, determine, select, configure and implement. The exam tests choosing the right design, not memorizing settings. Don't test quotas, prices, default values or exact API names unless the skill names them. Someone with a year of hands-on AWS design experience should know the answer without a lookup table.
- **Formats:** single-answer questions have 4 options and 1 correct answer. Multiple-response questions have 5 options, 2 correct (sometimes 3), and the stem ends "(Select TWO.)". Aim for roughly 75 percent single and 25 percent multiple-response.
- **Stems:** 2 to 4 sentences: a company, what it runs, what it needs, and the constraint. Then a question line such as "Which solution will meet these requirements?" Use a qualifier only when the scenario sets up that trade-off, and write it in capitals: "MOST cost-effectively", "with the LEAST operational overhead", "MOST highly available". Every option should be technically possible, so the qualifier decides.
- **Options:** complete designs in one or two sentences, with parallel wording. Distractors are designs that work but miss the stated constraint (more operational overhead, more cost, not highly available, a single AZ), or that use the right service with the wrong setting. Avoid options that are obviously broken.
- **Names:** use the guide's names. In-scope services only, distractors included (`in-scope-services.md`). The guide still names AWS Cost and Usage Report, AWS Data Pipeline and the AWS Snow Family. Where AWS has since renamed or limited one, keep the guide's name in the option and add a one-line note in the rationale only if a learner would otherwise be confused.
- **Weights:** security 30%, resilience 26%, performance 24%, cost 20%. Cost questions often reuse resilience and performance scenarios with a cost constraint, so make the constraint, not the service, the thing being tested.
- **Machine learning services** (Amazon Comprehend, Polly, Rekognition, Textract, Transcribe, Translate, Lex, SageMaker AI): recognition level only. Which managed service fits a business need, never model building or tuning.
- **Diagrams:** the exam has none, so describe topology in words.
- **Tags:** the services or concepts, for example `["rds", "multi-az", "disaster-recovery"]`.
